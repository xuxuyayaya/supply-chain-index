# 倡议书微信原生响应页

本目录是独立微信小程序。正文、公司选择、确认响应和 PDF 按钮均为原生页面。
PDF 在手机上用 Canvas 排版，写入小程序文件系统，以 wx.openDocument({fileType:'pdf',showMenu:true}) 打开。用户通过微信文件菜单保存或转发。文件为单页 A4 PDF，正文下方填写对应响应单位名称。无需访问 Render，也无需跳转系统浏览器。

## 发布前所需配置

1. 在微信开发者工具导入本目录，把 project.config.json 中 touristappid 替换成有发布权限的真实小程序 AppID。
2. 微信公众平台的开发管理中将 https://dkfile.istester.com 添加到 request 合法域名。PDF 本地生成，无需设置 downloadFile 合法域名。
3. 真机验证阅读至末尾、选择公司、其他单位、服务器提交、重新进入和原生 PDF 保存与转发。
4. 选择可识别的系统测试单位进行提交验证，勿代替实际企业响应倡议。
5. 检查通过后上传体验版，再由账号管理员完成审核和发布。发布后生成小程序码。当前源代码未发布，不能作为已修复的线上版本。
